# Image assets

Place images imported by Vue components in this directory, for example:

- founder portraits
- portfolio and case-study images
- service illustrations
- testimonial headshots
- decorative image assets processed by Vite

Use `public/` only for files that must keep a fixed public URL, such as the preloader logo, favicon, or social-sharing image.

Example:

```js
import founderImage from '@/assets/images/founder.webp'
```
